RITMO Android platform configuration

This folder contains the Android Gradle configuration, manifest, alarm permissions,
notification receivers and Kotlin MainActivity. The Gradle wrapper JAR and launcher
scripts are generated by Flutter on the developer machine / GitHub Actions.

From the RITMO project root, run:
  flutter create --platforms=android --org com.ritmo --project-name ritmo .
Then reapply these Android configuration files (or use the repository CI workflow,
which generates the wrapper and applies tool/configure_android.py automatically).

Important: pluginManagement repositories include google(), mavenCentral(), and
gradlePluginPortal() to resolve Kotlin Gradle plugin artifacts.
